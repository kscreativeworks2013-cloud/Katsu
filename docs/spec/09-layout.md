# 第8章｜ビジュアル主導の版面設計

8-1. 進め方（これまでと変える）

・**仕様を先に書き切らない。** 版面の良否は出力を見なければ判定できず、判定するのは利用者である。本章は判型と比較の観点だけを固定し、版面案は実装して PDF で提示する。
・各案の記述は方針10行程度にとどめる。詰めた仕様は採用案が決まってから書く。
・入力はモックエンジンの決定的な出力に固定する。同じ内容で版面だけを何度も出し直して比較できることが、実モデル接続より先に本章を置く理由（backlog 参照）。
・進行は3回に分ける。(a) 判型の決定（本節まで）、(b) 版面案3本の実装と PDF 出力、(c) 採用案の詰めと残り章への適用。

8-2. 判型：A4横（297×210mm）

現状は A4縦・1カラム流し込み、PowerPoint は 16:9。判型を A4横に統一する。

理由は次の2点に限る。

・**横位置素材に合う。** キービジュアルもムードボードのタイルも横位置が主で、A4縦では表紙でトリミングを強いられるか、上下に余白の出る単調な構成になる。
・**印刷が生き残る。** 16:9 を PDF の判型にすると A4 用紙では上下に帯が出るため、実質「印刷しない前提」になる。日本の広告案件では PDF を刷って回覧する場面が残っており、この選択肢を判型の段階で捨てない。判型は後から取り戻せない側の決定である。

解像度を理由にはしない：16:9 に物理寸法（338mm）を割り当てて ppi を比べるのは誤りで、画面専用の判型なら評価軸はスクリーン画素（1920／2560px）である。その基準では 2K 級の生成画像は 16:9 でも足りる。第7章 7-3 の制約は判型の選択とは独立している。

16:9 との関係：
・**PowerPoint は 16:9 のまま**とし、16:9 は A4横の版面から派生させる。
・そのために**版面は相対座標で定義する**（8-4）。判型ごとに版面を書き分けない。

帰結（(b) で反映する）：
・第7章 7-2 のスロット別必要ピクセル数は A4縦基準のため、A4横の配置幅で置き換える。`ImageSlot.printWidthMm` も同時に更新する（`low-resolution` 警告の判定根拠がここに依存している）。
・PDF レンダラのページサイズと余白、PowerPoint 側のスロット対応を差し替える。

8-3. 比較の観点

版面案は次の3点で比較する。判定は出力された PDF を見て行う。

・**画像の支配度**：表紙・ムードボード・ショットリストで、画像が面のどれだけを占めるか。
・**テキストの従属**：文章が画像に従属して配置されているか（見出しと本文が画像の邪魔をしていないか）。
・**1ページあたりの情報密度**：詰まりすぎ／薄すぎのどちらにも寄っていないか。ページ数は結果として出る。

8-4. 版面定義は相対座標で持つ

・版面（スロットの位置と大きさ、余白、文字サイズの段階）は、判型に対する**比率**で定義する。ミリやポイントの直値を版面定義に書かない。
・レンダラは判型（A4横 297×210mm、16:9 338×190mm 相当）を受け取り、比率を実寸に展開する。これにより 16:9 は A4横の版面からの派生になり、版面定義は1つで済む。
・比率で表せないもの（本文の最小可読サイズ、断ち落としの余白）だけを判型ごとの下限として持つ。
・印刷解像度の判定（第7章 7-2）は展開後の実寸（mm）で行う。`ImageSlot.printWidthMm` は版面定義から導出する値であり、手で並べた定数ではなくなる。

8-5. 版面案（実装済み。判定待ち）

同じ案件データ（モックエンジンの決定的な出力）から3本を出力する。
`npx vitest run --config tools/layout-preview/vitest.config.ts` → dist/layout-preview/*.pdf

A：エディトリアル（12ページ）
・表紙は全面ブリード。画像の上に暗幕を敷き、タイトルは左下に置く。
・章はテキストを版面の左62%に抑え、右側は画像のための余白として空ける。
・ブランド分析・撮影コンセプトなど画像を持つ章は、上42%に画像帯を敷いてから本文へ落とす。
・ムードボードは3×2の大判タイル＋キャプション。1枚あたりの面積が最も大きい。
・ショットリストは横4枚のフィルムストリップで、カットの流れを一列で見せる。仕様は帯の下。
・テキストだけの章はまとめて流し込み、白いだけの面を作らない。
・画像の支配度：中。テキストの従属：明確（行長を抑え、常に画像が先）。密度：中。

B：ギャラリー（9ページ）
・画像を最優先し、テキストはキャプションと短い本文に落とす。余白は最小（3%）。
・ムードボードは4×3の断ち落としグリッド。タイル間の隙間も余白も持たない。
・画像を持つ章は上62%を画像帯にし、本文は帯の下だけで完結させる。
・ショットリストもグリッドで扱い、フィルムストリップは使わない。
・画像の支配度：最大。テキストの従属：強い（説明はほぼ従属物）。密度：低。

C：コンタクトシート（9ページ）
・表紙は上66%が画像、下33%に案件情報。紙面として最も落ち着く配置。
・ムードボードは6×3の小タイルを1ページに収め、全点を一覧できるようにする。
・テキストは2段組。1面あたりの情報量が最も多く、総ページ数は最少。
・ショットリストはグリッド＋仕様の並記。
・画像の支配度：低〜中。テキストの従属：弱い（テキストが面を占める場面がある）。密度：高。

8-6. 実装した規則（実写で確かめたもの）

・**トリミングは上寄せ**：縦にはみ出す分は下から78%削る。中央基準は人物写真で必ず頭が落ちる（表紙・タイル・ストリップの全てで再現した）。
・**枠を伸ばしすぎない**：タイルの縦横比の上限は 1.5:1。半端な行は行ごと中央に寄せる。フィルムストリップの枠幅は枚数に関わらず常に4分割。縦位置素材を横長の枠へ入れると帯になる。
・**タイル面には台紙を敷く**：ムードボードのタイル領域のみ、紙色より1〜2段暗いグレージュ（#E5E2DB 相当）。白背景の素材は輪郭が立ち、暗い素材は逆に浮く。罫線は素材ごとに処理が変わる版面になり、紙色を落とすと素材1点のために全体のトーンが動くため採らない。トレードオフとして、前半の中でこの面だけ地色が変わる。
・**警告は成果物にも残す**：warn 級の警告を最終面「出力時の注意」に刻む。同一文は畳む（同じ画像が複数スロットに出ると同文が並ぶため）。
・**配置幅は版面から導く**：`slotWidthMm()` が版面定義から算出し、印刷解像度の判定はその実寸で行う。テンプレート側に mm の定数を置かない（版面を動かすと判定だけが古くなるため）。

8-7. 次にやること

・ブランドカラーのテンプレート差し替え（未着手）。ブランドのパレットから紙色・差し色・台紙のトーンを導く。
・トリミング位置の指定手段（未着手）。自動の上寄せで足りない素材のために、アセット単位で焦点を持てるようにする。3:2 の横位置を表紙帯へ流すと、主題は残るが上端が切れる。
・版面設計の完了時点で実案件を1本通し、クライアントへ出せる品質かを確認して以降の優先順位を見直す。
