# 第1章｜プロジェクト概要

プロジェクト名：Luxury Beauty Visual Proposal OS

目的：
ラグジュアリー／ビューティー領域の広告撮影案件について、案件情報・ブランド資料を入力するだけで、企画から提案書、AI生成用プロンプトまでを一貫して作成できる統合システムを構築する。

想定ユーザー：
・ラグジュアリーフォトグラファー
・ビューティーフォトグラファー
・クリエイティブディレクター
・プロデューサー
・広告代理店
・ブランド担当者

解決する課題：
・案件ごとに提案資料をゼロから作成する負担
・ブランド分析／競合分析にかかる時間
・提案内容やトーン＆マナーのばらつき
・日本語版と英語版を別々に制作するコスト
・AIごとにプロンプトを書き換える手間
・企画からショットリスト、見積もり、提案書までの分断

提供価値：
・提案品質の標準化と高品質化
・企画制作時間の短縮
・ブランドトーンの一貫性
・複数AIに最適化されたプロンプトの一括生成
・日本語／英語提案の同時展開
・PowerPoint／PDF等へのワンクリック出力

主要アウトプット：
ブランド分析、競合分析、撮影コンセプト2〜3案、ムードボード構成案、ショットリスト、絵コンテ、ライティングプラン、機材構成、スタッフ構成、スケジュール、見積もり、リスク管理、日英Proposal、PowerPoint、PDF、AI別プロンプト。

対応AI：
ChatGPT、Claude、Gemini系、ImageFX、Midjourney、Flux。
モデル名を固定せず、将来のモデル変更・追加に対応できる設定方式とする。
