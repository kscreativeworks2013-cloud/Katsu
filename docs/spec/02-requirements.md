# 第2章｜要件定義・入力フォーマット

基本情報：
・プロジェクト名
・クライアント名
・ブランド名
・案件名
・提案日
・納期
・予算
・使用言語

ブランド情報：
・ブランドURL
・ブランドガイドラインPDF
・ロゴ
・ブランドコンセプト
・ターゲット顧客
・競合ブランド

撮影内容：
・ジャンル（ビューティー、スキンケア、メイク、フレグランス、ファッション等）
・商品名
・撮影目的（広告、SNS、EC、雑誌、OOH、Web、動画等）
・キーワード
・必須カット
・NG事項
・参考資料（Web、URL、PDF、画像等）

クリエイティブ設定：
・世界観
・カラーパレット
・ライティング
・レンズイメージ
・構図
・演出
・質感
・レタッチ方針

制作条件：
・撮影日数
・ロケーション／スタジオ
・モデル人数
・ヘアメイク
・スタイリスト
・撮影機材
・納品形式

生成オプション：
ブランド分析、競合分析、コンセプト、ムードボード、ショットリスト、絵コンテ、ライティングプラン、スケジュール、見積もり、日本語提案書、英語Proposal、PDF、PowerPoint、Word、Markdown。
