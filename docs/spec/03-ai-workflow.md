# 第2章｜AIワークフロー

1. 案件情報を入力
2. ブランドURL・PDF・参考資料・ロゴ等を読み込む
3. ブランドの世界観、トーン、ターゲット、ビジュアルコードを抽出
4. 競合ブランドを分析し、差別化ポイントを整理
5. 撮影コンセプトを2〜3案生成（各案にタイトル、狙い、ストーリー、ビジュアル方向性）
6. ムードボード構成案を生成
7. ショットリストを生成
8. 絵コンテ／フレーム構成案を生成
9. ライティングプラン、レンズ、機材構成を生成
10. スタッフ構成・スケジュール・見積もりを生成
11. ChatGPT／Claude／Gemini系／ImageFX／Midjourney／Flux向けにプロンプトを最適化
12. 日本語Proposalを生成
13. 英語Proposalを生成
14. PowerPoint／PDF等へ出力
15. 将来的にポートフォリオから案件に合う作品を自動選定
16. 将来的にブランドカラー等に合わせ提案書デザインを自動調整
